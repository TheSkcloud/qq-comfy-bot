# 晚风聊天引擎与能力开关迭代说明（2026-11-15）

本次完成的是总体方案的一次经过验证的增量迭代，不代表 G0–G7 全部完成。

## 本次变化

- 短句接续、引语和历史指代可进入语义分析；双阶段聊天的前台关闭重复 Thinking，修复实测格式失败。
- 新增本轮 DialoguePlan，提供回应动作、深度及叙述线索；快照记录规划、能力模式与讨论版本。
- 修复“别的都不说”“不想把话说得太死”误停聊；引述中的停聊命令不直接执行。
- 用户事实增加主体归属检查，拒绝第三人近况、引语自称及听说类陈述；保留同主语的并列偏好。该规则保守，可能漏记复杂表达。
- JSON 控制字符异常仅恢复正文，不接受恢复结果中的记忆、情绪、状态或绘图授权。
- 统一 OFF/MANUAL/ASSISTED/AUTO 解析及配置版本，接入绘图准入、排队执行、主动分享和控制台。旧 IMAGE_MODE=off 兼容为 MANUAL；真正 OFF 也禁止明确索图。辅助模式当前仅支持已有明确请求的确认，不代表完整主动建议流程已经落地。
- 普通聊天在手动模式下不再错误发送绘图失败提示；排队中关闭绘图会在提交前阻止任务。
