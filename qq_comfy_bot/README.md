# 项目说明

晚风是一个 Python QQ 角色机器人项目，使用 NapCat 接收和发送消息，通过 DeepSeek 兼容接口生成对话，并可调用本地 ComfyUI 工作流生成插画。

## 主要能力

- 角色设定与结构化对话。
- 会话上下文、事实记忆和关系状态。
- 虚拟角色日程与聊天节奏控制。
- 明确索图及受策略控制的图片分享。
- ComfyUI 图片任务、质量检查与发送状态处理。
- 本地管理界面和配置文件。

虚拟日程描述的是角色设定，不代表用户的真实安排。项目不会要求公开私人数据库或聊天记录。

## 本机运行

请按示例配置准备 API 服务地址、模型名称、NapCat 连接信息及必要凭据，再启动对应服务。真实密钥应通过本机环境配置提供，不要写入源码或提交到 Git。ComfyUI 工作流和模型由部署者在本机维护。

项目依赖和启动入口请参照仓库中的依赖清单与启动脚本。
