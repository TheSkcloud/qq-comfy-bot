# 项目说明

晚风是一个 Python QQ 角色机器人项目，使用 NapCat 接收和发送消息，通过 DeepSeek 兼容接口生成对话，并可调用本地 ComfyUI 工作流生成插画。

## 主要能力

- 角色设定与结构化对话。
- 会话上下文、事实记忆和关系状态。
- 虚拟角色日程与聊天节奏控制。
- 明确索图及受策略控制的图片分享。
- ComfyUI 图片任务、质量检查与发送状态处理。
- 本地管理界面和配置文件。

虚拟日程描述的是角色设定，不代表用户的真实安排。项目不会要求公开私人数据库或聊天记录。

## 本机运行

请按示例配置准备 API 服务地址、模型名称、NapCat 连接信息及必要凭据，再启动对应服务。真实密钥应通过本机环境配置提供，不要写入源码或提交到 Git。ComfyUI 工作流和模型由部署者在本机维护。

项目依赖和启动入口请参照仓库中的依赖清单与启动脚本。

### 聊天与绘图

纯文本输入达到 `CHAT_SPLIT_MIN_CHARS` 时，先结合最近对话和本地记忆整理当前话题，再让第二次请求用整理结果写回复。默认 240 字符，设为 `0` 可关闭双调用。整理请求失败时，回复使用已读取的本地上下文。较新的消息会取消尚未完成的旧处理。短聊在读取本地上下文后用一次请求完成。

日常 `/拍照` 优先用本地角色和虚拟日程的画面预设。具体场景或人物约束交给已受理的绘图任务；用户只为当前图片指定的设定进入该任务的快照。最终提示词通过本地预检后才进入渲染队列，成图仍按原有质检流程验收。
