## 11 月 2 日：对话深度、独立创意和 GPU 空闲卸载（前一阶段）

### 对话与 Thinking

- `dialogue_depth.py` 管理每会话话题、完成轮次、讨论摘要、观点、未决/已解决问题。普通闲聊 A 不启用 Thinking；同话题四次实质交流全部收到 QQ 文字回执后，下一次实质交流进入 B；复杂分析、因果、比较、代码问题立即 C。复杂话题的简短延续保留 C，简单确认仍快速回复。
- `preferences.json` 的 `thinking_after_substantive_turns=4` 可设 1—20。按逻辑回复计一次，不按 QQ 分段计数；“嗯/哈哈”等确认不累积。明确切换重计，暂时插话保留原主题，返回时恢复；同次模型输出的有原话依据的语义更新补充本地判断，不增加摘要 API。
- 摘要为有界讨论记录，不直接写成用户长期事实；保留早期锚点与近期观点。Thinking 不改变 persona 或关系推进规则。隐式主题判断仍受本地规则与模型准确度限制，不能保证任意自然语言切换第一轮都判对。

### 创意到绘图准备

- `image_concept.py` 定义13字段 `creative_brief`：concept / narrative_moment / subject / action / expression / gesture / props / environment / atmosphere / focal_point / emotional_intent / context_connection / creative_reason。先有叙事瞬间、上下文连接和创作理由，再由 `shot_director.py` 选择镜头；不是仅替换拍摄角度。
- Explicit、Life、Comfort、Comic 共用检查。有效主规划直接复用；缺创意核心或视觉场景时，后台一次 Thinking 补全同时准备创意与英文视觉字段。辅助字段可从同次合法场景恢复，创意核心不能凭空填默认值。用户明确动作/服装/地点/镜头优先，原身份和持续状态保留。
- 创意动作/手势/道具/表情进入 image_plan，氛围/焦点进入最终提示；导演根据动作及创意焦点选择景别。任务持久保存原始创意、规范创意、shot_plan、final_visual_scene、提示与运行图。
- 明确索图的主响应为空或 JSON 残缺：只恢复安全聊天正文，保持原状态，交独立视觉规划一次补全。补全仍不合格则持久记录失败和任务 ID，不将半成品交给 GPU。普通 Thinking 正文缺失时最多一次45秒正文恢复，禁止恢复响应修改场景/记忆或触发图片。
- 深聊 B/C 不再插入无关日常 Life 兜底，明确索图及有依据的安慰/漫画机会仍可处理。11月2日已修复的动作外观索图和上下文承接规则继续有效。

### GPU 生命周期与设置

- `gpu_memory_manager.py` 默认启用；`.env.example`：`GPU_IDLE_UNLOAD_ENABLED=1`、`GPU_IDLE_TIMEOUT_SECONDS=3600`、`GPU_IDLE_CHECK_INTERVAL_SECONDS=60`。真实 `.env` 不改。
- 默认从实际 GPU 完成时间开始计空闲，记录 `data/gpu_memory_state.json`；重启读取账本，无有效时间则从启动起计并保留启动宽限。诊断构造器不会覆盖运行中账本。外部队列活动/历史也会延后空闲计时。
- 机器人准备/排队/执行任务和外部 `/queue` 均参与检查；提交结果不明保守阻止卸载；状态接口不可用不卸载。机器人提交与卸载共用异步锁，提交前再查队列，期间到达的内部任务等卸载检查结束后继续。
- 核对本机 ComfyUI 0.34.0 / `12d52794`：官方 `POST /free`，参数 `unload_models:true, free_memory:true`。接口置标志，官方工作线程在执行安全点卸载模型并清理缓存；不杀进程、不重启服务、不调用全局 interrupt。后续普通工作流提交路径保留自动加载能力。
- `/free` 返回并非卸载完成证明；继续观察队列与显存，记录前后设备总占用和 Torch 保留量。无可测变化时明确记 `unload_requested_no_measurable_change`，不会伪报释放量。外部程序提交与检查之间无跨进程原子锁，最终执行安全由官方工作线程串行处理。
- 事件日志 `data/gpu_memory.jsonl`；结果不明的提交需有匹配历史才能解锁，无法确认时可能长期跳过自动卸载，需要人工核查。日志/账本均为私人运行数据，不上传。

## 部分完成 / 仍需观察

- 导演、镜头历史、提示控制和 QA 闭环已接通，但“20—30 张稳定覆盖各种实际景别且每张身份/服装/动作准确”没有完全达成；远景和纯局部的模型服从度、手指结构、动作以及部分漫画仍需后续校准。没有替换用户原模型/LoRA 来掩盖这些问题。
- 自动分享的长时间自然度、真实日常频率和关系连续性没有在本轮短期测试中充分证明。未重写人设和好感机制。
- ComfyUI/QQ 提交回执不明时以防重复优先，留待人工检查；不能保证取消已在 GPU 运行中的作业。正在运行的任务不会跨进程重启自动恢复。
- 实图质量仍依赖原模型与视觉审核能力；没有把 QA 通过率当成人工画质满意度，也没有承诺每张耗时固定。
