# 晚风 QQ 角色机器人

基于 Python、NapCat、DeepSeek 兼容接口和 ComfyUI 的 QQ 角色对话项目。

项目包含角色对话、会话上下文、虚拟日常、记忆管理和异步绘图等模块。绘图通过本地 ComfyUI 工作流执行，保留项目使用者配置的模型与工作流。

## 配置与隐私

运行所需凭据应保存在本机环境配置中，不要提交 API 密钥、机器人令牌、私人数据库、聊天记录或运行日志。示例配置仅用于说明变量格式。
