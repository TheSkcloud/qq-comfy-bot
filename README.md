# 晚风 · QQ 虚拟角色机器人

QQ 私聊角色陪伴、ComfyUI 绘图、主动生活分享与 Windows 托盘管理。

## 源码包

[下载当前源码包](QQ机器人_速度主动性托盘修复.zip)

版本：2026-11-01。解压后查看 qq_comfy_bot/README.md，安装 requirements.txt，按 .env.example 配置本机密钥和账号。

包含：并行聊天与绘图、较小原生尺寸、绘图描述缺失补全、主动绘图机会和托盘退出。模型权重、QQ/NapCat 与 ComfyUI 服务需另行配置。

此备份不包含真实密钥、聊天数据库、运行日志、生成图片或本机启动配置。
